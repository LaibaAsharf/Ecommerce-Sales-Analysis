# 🛍️ Ecommerce Sales Analysis Dashboard

## Project Overview
This project is an interactive Ecommerce Sales Analysis Dashboard developed using Python, Pandas, and Streamlit. It helps analyze sales performance, profit, loss, customer behavior, product performance, and payment methods through interactive visualizations.

## Features
- Key Performance Indicators (KPIs)
- Total Sales, Profit, and Loss Analysis
- Sales Analysis by City, Category, and Product
- Customer Type Analysis
- Quantity Sold by Product
- Sales vs. Profit Comparison
- Sales Trends Over Time
- Customer Ratings Analysis
- Interactive City and Category Filters
- Sales Data Table

## Technologies Used
- Python
- Pandas
- Streamlit
- CSS
- Jupyter Notebook
- Scikit-learn (Label Encoding practice)

## Project Files
- `app.py` – Main Streamlit dashboard application
- `encoding.ipynb` – Data encoding practice
- `style.css` – Dashboard styling
- `ecommerce_sales_dashboard_data_with_loss.csv` – Ecommerce dataset

## Dataset
The dataset contains 250 ecommerce orders with information about customers, products, sales, costs, profits, discounts, payment methods, and delivery.

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/LaibaAsharf/Ecommerce-Sales-Analysis.git
```

2. Navigate to the project directory:

```bash
cd Ecommerce-Sales-Analysis
```

3. Install the required libraries:

```bash
pip install streamlit pandas
```

4. Run the dashboard:

```bash
streamlit run app.py
```

## Project Objective
The objective of this project is to explore ecommerce sales data, identify business performance trends, and present meaningful insights through an interactive dashboard.
